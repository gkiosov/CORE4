## ✨ Возможности

- 🧱 **Модульная сетка** — 12-колоночная система на CSS Grid (как Bootstrap, но лучше)
- 🎨 **Перцептивные цвета** — Палитра на OKLCH (стандарт 2026) вместо устаревшего HSL
- 🌓 **Тёмная/светлая тема** — Автоматическое переключение через CSS-переменные
- 📱 **Адаптивность** — 6 брейкпоинтов (`xs`, `sm`, `md`, `lg`, `xl`, `xxl`)
- 🔮 **Динамические компоненты** — Модалки, аккордеоны, табы на чистом JS без jQuery
- ♿️ **Доступность** — Управление с клавиатуры (Tab, Escape, Focus Trap)

## 🚀 Быстрый старт

```bash
# 1. Склонировать репозиторий
git clone https://gitverse.ru/kiosov/CORE4.git

# 2. Установить зависимости
npm install

# 3. Запустить режим разработки (с авто-перезагрузкой)
npm run dev

# 4. Собрать продакшен-версию
npm run build
