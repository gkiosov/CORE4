# 🎨 CORE4 Design System

> **Модульная и высокопроизводительная дизайн-система на SCSS и JavaScript с поддержкой OKLCH-цветов, ленивой загрузкой компонентов и доступностью как встроенной функцией.**

## 📖 Обзор

**CORE4** — это не просто коллекция UI-компонентов. Это **модульная и производительная дизайн-система**, спроектированная с инженерным подходом для создания сложных, доступных и легко масштабируемых интерфейсов. Она представляет собой гармоничный синтез современных CSS-методологий и передовых JavaScript-практик, где каждый аспект — от цветового пространства до загрузки компонентов — продуман и оптимизирован.

В основе системы лежит несколько ключевых архитектурных решений, которые выделяют её на фоне типовых решений:

*   **Промышленный подход к стилям: ITCSS + OKLCH**. Система построена на архитектуре **ITCSS (Inverted Triangle CSS)**, что обеспечивает идеальную организацию кода: от глобальных настроек до конкретных компонентов. Использование **перцептивно-равномерного цветового пространства OKLCH** — индустриального стандарта 2026 года — гарантирует, что цвета всегда выглядят гармонично и предсказуемо на любых экранах.

*   **Модульный JavaScript с ленивой загрузкой (Lazy Loading)**. Вместо монолитного скрипта, CORE4 использует **модульную архитектуру с динамическими импортами**. JavaScript-компоненты загружаются асинхронно **только тогда, когда они реально появляются в DOM**. Это кардинально ускоряет начальную загрузку страницы. Единый **EventManager** и строгая очистка слушателей в методе `destroy()` гарантируют отсутствие утечек памяти.

*   **Доступность (A11y) как встроенная функция**. Система изначально проектируется как **ARIA-first**. Все интерактивные компоненты поддерживают навигацию с клавиатуры (Tab, Escape, стрелки), корректно управляют фокусом (Focus Trap) и содержат все необходимые ARIA-атрибуты.

*   **Глобальная адаптивность через логические свойства**. Вместо физических `margin-top` и `padding-left` система построена на **логических свойствах** (`margin-block-start`, `padding-inline-start`). Это обеспечивает **автоматическую поддержку RTL-языков** (арабский, иврит) без необходимости писать отдельные правила.

*   **Инженерная инфраструктура для реальной разработки**. Проект идёт дальше простого набора файлов, предлагая полноценную инфраструктуру: дизайн-токены, Webpack с code splitting, и управление жизненным циклом через `app.reinit()` для динамического контента.

В итоге, CORE4 — это **инженерная система**, которая позволяет разработчикам и дизайнерам сосредоточиться на логике и пользовательском опыте, будучи уверенными в том, что фундамент интерфейса надёжен, производителен и соответствует всем современным веб-стандартам.

## ✨ Основные возможности

*   🧱 **Модульная сетка** — 12-колоночная система на CSS Grid
*   🎨 **OKLCH-цвета** — перцептивно-равномерные, стандарт 2026
*   🌓 **Тёмная/светлая тема** — системная + ручное переключение через `data-theme`
*   📱 **Адаптивность** — 6 брейкпоинтов (`xs`, `sm`, `md`, `lg`, `xl`, `xxl`)
*   🔮 **Динамические компоненты** — модалки, аккордеоны, дропдауны, кнопки на чистом JS
*   ♿️ **Доступность** — навигация с клавиатуры, Focus Trap, ARIA-атрибуты
*   ⚡ **Ленивая загрузка** — JS-модули загружаются только при необходимости
*   🔄 **Реинициализация** — `app.reinit()` для динамически добавляемого контента
*   🔤 **Кастомные шрифты** — InterTight и JetBrains Mono (OFL-1.1)
*   📦 **Готовая сборка** — Webpack + Babel + минификация

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/gkiosov/CORE4.git
cd CORE4
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск сервера разработки

```bash
npm run dev
```

Открой `http://localhost:3000` — страница автоматически обновляется при изменениях.

### 4. Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `build/`.

## 📁 Структура проекта

```
core4/
├── source/
│   ├── assets/                 # Шрифты, иконки, изображения
│   ├── scss/
│   │   ├── 1-settings/         # Переменные, темы, сбросы
│   │   ├── 2-tools/            # Функции и миксины
│   │   ├── 3-generic/          # Базовые стили, шрифты, анимации
│   │   ├── 4-objects/          # Сетка и утилиты
│   │   ├── 5-components/       # Компоненты
│   │   └── main.scss           # Главный файл импорта
│   │
│   └── js/
│       ├── core/               # Конфиги, хелперы, EventManager
│       ├── modules/            # Модули с ленивой загрузкой
│       ├── utilities/          # DOM, клавиатура, Focus Trap, вьюпорт
│       └── main.js             # Точка входа
│
├── build/                      # Сборка (генерируется)
├── docs/                       # Документация
├── webpack.config.js
├── package.json
└── README-RU.md
```
